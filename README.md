# StockPilot_FE

Frontend repository for **StockPilot — Smart Inventory and Pricing Decision Support System**.

## Core stack
- React.js + TypeScript + Vite
- Recharts
- REST API integration with Node.js/Express backend
- JWT authentication + RBAC
